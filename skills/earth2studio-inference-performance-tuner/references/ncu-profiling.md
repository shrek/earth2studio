# Bounded Nsight Compute workflow

Run NCU only after HTA records a critical-path kernel, exact question, and selector. Check availability without changing the system. Produce a print-only capture command, selector, launch skip/count, section set, paths, and fingerprint; obtain separate approval bound to it.

Start with the default set and at most ten launches. Preserve spec, manifest, log, `.ncu-rep`, CSV, and normalized JSON. Treat replay timing as diagnostic evidence. Skip NCU for explained data, host, output, checkpoint, communication, or launch bottlenecks. Do not install tools, use sudo, enable counters, or change capabilities.
